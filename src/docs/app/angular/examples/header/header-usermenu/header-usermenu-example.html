This example shows how to implement a simple 'login'/'logout' button.

The `sbb-header-button` is rendered conditionally:

  • if the user is not logged-in, it displays a 'Login' label and it has a click handler for login;
  • if the user is logged-in, it shows the username and it has a connected `sbb-menu` which allows to logout.
